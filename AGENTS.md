# Hướng dẫn cho agent

- Logic gameplay ở `src/game.js`; renderer và headless dùng chung logic.
- Trước khi kết thúc thay đổi chạy `npm test` và `npm run build`.
- Không thay Test Contract hoặc sửa output bằng tay. Ghi giả định và kết quả chưa kiểm chứng trong docs.
- Không commit khóa bí mật hoặc thư mục node_modules/dist.
